# TOB求解器 (Towers of Babble Solver)

输入可用字母，根据要求筛选单词，可以方便地找到指定属性的防御塔、采集塔或模组。也能计算如何清空字母。

- 网页版
  - 韩语原版：https://sidequest.hcmll0120.workers.dev/apps/towers-of-babble/
  - 中文版：https://somall-dumpling.github.io/towers-of-babble-solver-zh_CN/
- 原版制作过程：https://sidequest.hcmll0120.workers.dev/tools/towers-of-babble/

## 如何本地运行

下载 `index.html` 文件，用浏览器打开。

## 数据来源

- `index.html` 内置英语词典和游戏中每个单词的数值。
- 单词分类（名词·动词·形容词·副词）基于 WordNet，可能与游戏内的分类不同。
